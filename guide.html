Set up My spending

Track every Apple Pay purchase automatically, see a daily limit, and get alerts when you go over. Setup takes about 15 minutes on your iPhone.

🔒
Your data stays yours. Purchases are saved in your own private GitHub repository. Nobody else, including the person who shared this, can see them.
1

Your GitHub account

No account yet? Make a free one, then come back.

Make a GitHub account

The buttons below fill in your name for you.

2

Make your private repository

This is where your purchases are saved.

  1. Check the name is spend-data.
  2. Make sure Private is picked.
  3. Turn on Add README, then tap Create repository.
Create spend-data

It must be Private. The app refuses a public repository so your purchases never become public.

3

Add the alerts file

This lets your repository send you notifications: what you can spend each morning, an alert when you go over, and a 9 PM summary.

  1. Tap the button. The file is already filled in.
  2. Tap Commit changes, then Commit changes again.
Add the alerts file

Type your username in step 1 first.

4

Make a token

The token lets your phone write purchases to your repository, and nothing else.

  1. Tap the button. The name, expiry and permission are filled in.
  2. Under Repository access, pick Only select repositories and choose spend-data.
  3. Check that Issues says Read and write.
  4. Tap Generate token and copy it. You only see it once, so keep it in Notes for the next steps.
Make the token

It lasts a year. GitHub emails you before it runs out.

5

Get the two Shortcuts

These send each purchase to your repository the moment you pay.

  1. When you add each one, it asks two questions. Paste your token, and type your repository: your-name/spend-data
  2. Open the Shortcuts app, tap Automation, then +.
  3. Pick Wallet, choose your cards, pick Run Immediately, then Next. Choose Run Shortcut and select Log tap.
  4. Make a second automation: pick Notification, choose the Wallet app, pick Run Immediately. Choose Run Shortcut, select Log Wallet alert, and pass the notification in as the input.

The first catches tap-to-pay at stores. The second catches online Apple Pay. If both fire for one purchase, the app counts it once.

6

Put the app on your Home Screen

  1. Open the app link below in Safari.
  2. Tap Share, then Add to Home Screen.
  3. Open it from the new icon, paste your token, and tap Save and load.
Open the app
7

Finish in the app

  • Tap Set limit at the top to pick how much you want to spend a day.
  • At the bottom, open Alerts and settings and tap Turn on alerts. A "Spending alerts are on" notification means it all works.
  • Pay for something with Apple Pay. It shows up in the app within a minute.

That's it. 🎉

Stuck? Most problems are the token: it needs Issues: Read and write and access to spend-data. You can make a new one any time and enter it again under Alerts and settings, then Forget the token.
